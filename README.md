# 🧮 Interactive Web Calculators

A lightweight collection of interactive, web-based calculation and conversion tools. Built with standard HTML and Vanilla JavaScript, this project demonstrates foundational DOM manipulation, event handling, and client-side logic.

## 📁 Project Structure

The repository is organized into three standalone web utilities, each consisting of an HTML structure file and a dedicated JavaScript logic file:

*   **🎂 Age/Birth Calculator**
    *   `Birth.html`: The user interface for inputting birth data.
    *   `Birth.js`: The underlying logic to calculate age metrics based on the provided input.
*   **🎓 Grade Evaluator**
    *   `Grades.html`: The frontend form for entering academic scores.
    *   `Grades.js`: The processing script that evaluates the inputted scores, likely calculating averages, GPAs, or pass/fail statuses.
*   **🔄 Unit/Currency Converter**
    *   `convert.html`: The interface for selecting and inputting conversion metrics.
    *   `Converter.js`: The mathematical logic handling the dynamic conversion between different units or values.

## 🚀 How to Run

Because this project is built using purely client-side technologies, no backend server or package installation is required.

1.  Clone or download the repository to your local machine.
2.  Navigate to the `Raghad Hamdy Ahmed lab 1` directory.
3.  Double-click any of the HTML files (`Birth.html`, `Grades.html`, or `convert.html`) to open them directly in your preferred web browser.

## 🛠️ Tech Stack

*   **Markup:** HTML5
*   **Scripting & Logic:** Vanilla JavaScript (ES6+)
